# youtube-customization
A collection of Youtube themes I originally made for the 'Enhancer for Youtube' extension, but it will work with other tools if you have them set up already.

To use, simply pick your theme and open the corresponding file. Copy all text inside the theme file of your choice, then open the Enhancer for Youtube configuration windows and paste the copied text into the 'Custom Theme' text box (make sure to check the custom theme box). Of course you may use other CSS injection tools such as Stylus or Tampermonkey and it will work.

If using Enhancer for Youtube, I would recommend changing your 'controls' to be placed inside the video player, not below. (Firefox extensions > Run Enhancer for Youtube > Controls > Place controls within the video player)
